Настройка OSM на Windows 11 с WSL Ubuntu

Полное руководство по настройке рабочего окружения для слияния и развертывания карт OpenStreetMap

Время чтения: 15 мин Январь 2024 Windows / Linux / Docker
Windows 11 WSL 2 Ubuntu OpenStreetMap Docker Osmosis

Данное руководство описывает процесс настройки рабочего окружения для слияния и развертывания карт OpenStreetMap в операционной системе Windows 11. В качестве основной среды используется Windows Subsystem for Linux (WSL 2) с дистрибутивом Ubuntu. Этот подход позволяет выполнять ресурсоемкие операции с картами в изолированном и оптимизированном Linux-окружении, сохраняя при этом полную интеграцию с файловой системой Windows и удобство работы.

1. Установка WSL и Ubuntu

Первым шагом является установка подсистемы WSL и дистрибутива Ubuntu по умолчанию. Для этого выполните в PowerShell (от имени администратора) следующую команду:

PowerShell (Администратор) 
wsl --install

После завершения установки и перезагрузки компьютера запустится процесс первоначальной настройки Ubuntu: вам будет предложено создать имя пользователя (никнейм) и пароль для новой учетной записи в WSL.

Вход в среду WSL возможен двумя способами:

  • Выполнив команду wsl в PowerShell или терминале Windows.
  • Запустив приложение "Ubuntu" из меню "Пуск" (рекомендуется запускать от имени администратора для избежания проблем с правами доступа к файлам на дисках Windows).

2. Настройка буфера обмена в терминале Ubuntu

По умолчанию стандартные сочетания клавиш Ctrl+C / Ctrl+V в окне терминала Ubuntu не работают для копирования и вставки текста.

Для включения этой функции:

  1. Щелкните правой кнопкой мыши на заголовке окна Ubuntu.
  2. Выберите пункт "Свойства".
  3. В открывшемся окне найдите и поставьте галочку в пункте: "Использовать сочетания клавиш Ctrl+Shift+C/V в качестве команды копирования и вставки".

Теперь для копирования текста в терминале используйте Ctrl+Shift+C, а для вставки — Ctrl+Shift+V.

3. Слияние карт (файлов .osm.pbf) с помощью Osmosis

Существует несколько способов слияния карт, но наиболее стабильным и рабочим на практике оказался метод с использованием утилиты Osmosis (попытки использовать osmium приводили к ошибкам с повторяющимися данными, которые не удалось разрешить).

3.1 Подготовка файлов карт

  1. Скачайте необходимые региональные карты в формате .osm.pbf с сайта Geofabrik: https://www.geofabrik.de/.
  2. Поместите скачанные файлы в удобную для вас папку. В рамках примера используется путь: /mnt/e/osm_maps.

3.2 Установка Osmosis в WSL (Ubuntu)

Ubuntu Terminal 
sudo apt update
Установка Java Runtime Environment 
sudo apt install default-jre -y
Установка Osmosis 
sudo apt install osmosis -y
Проверка установки 
osmosis --version

3.3 Процесс слияния

Переход в папку с картами 
cd /mnt/e/osm_maps
Слияние файлов карт 
osmosis --rb file_1.osm.pbf --rb file_2.osm.pbf --merge --wb final_final.osm.pbf

Где final_final.osm.pbf — имя итогового файла.

Что происходит после запуска команды:

  • В консоли появится сообщение: "INFO: Pipeline executing, waiting for completion."
  • Процесс может занять длительное время в зависимости от размера карт.
  • После успешного завершения вы увидите: "INFO: Pipeline complete. INFO: Total execution time: X minutes X seconds."
  • В случае ошибки вывод будет выделен красным цветом с описанием проблемы.
Примечание: Если кажется, что процесс "завис", нажмите клавишу Enter в консоли — иногда вывод сообщений может буферизоваться. Также можно проверить размер итогового файла в папке — если он увеличивается, значит процесс идет.

3.4 Проверка целостности полученного файла

После слияния рекомендуется проверить итоговый файл на отсутствие ошибок.

Проверка с помощью Osmium 
osmium check-refs final_final.osm.pbf

Успешный вывод выглядит примерно так:

There are 161180184 nodes, 9010024 ways, and 227816 relations in this file. Nodes in ways missing: 0

С помощью Osmosis (проверка или вывод статистики):

Проверка через Osmosis 
osmosis --rb final_final.osm.pbf --v

или

Статистика через Osmosis 
osmosis --rb final_final.osm.pbf --stat

4. Развертывание карты с помощью Docker Tile Server

4.1 Установка и настройка Docker

  1. Установите Docker Desktop для Windows с официального сайта.
  2. После установки откройте настройки Docker (Settings).
  3. Перейдите в раздел Resources → WSL Integration.
  4. Включите интеграцию для вашего дистрибутива Ubuntu.
  5. Примените изменения и перезапустите Docker.

4.2 Импорт карты в базу данных

Вернитесь в терминал Ubuntu и выполните команду импорта. Команда монтирует файл карты в контейнер и запускает процесс его обработки.

Важно: Замените /mnt/e/osm_maps/final_final.osm.pbf на актуальный путь к вашему итоговому файлу.
Импорт карты в Docker 
time docker run -v /mnt/e/osm_maps/final_final.osm.pbf:/data/region.osm.pbf -v openstreetmap-data:/var/lib/postgresql/15/main overv/openstreetmap-tile-server import

Особенности процесса:

  • Процесс импорта очень долгий (часы) и сильно зависит от размера файла .osm.pbf.
  • В конце вы получите отчет о времени выполнения, например:
real 118m29.612s user 0m0.267s sys 0m0.194s

4.3 Запуск tile-сервера

После успешного импорта запустите сервер следующей командой:

Запуск сервера карт 
docker run -p 8080:80 -v openstreetmap-data:/var/lib/postgresql/15/main -d overv/openstreetmap-tile-server run

4.4 Проверка работы

Откройте веб-браузер и перейдите по адресу: http://localhost:8080/.

Если все шаги были выполнены корректно, вы увидите интерактивную карту OpenStreetMap, работающую на вашем локальном сервере.

Итог

Вы успешно настроили среду WSL Ubuntu на Windows 11, объединили несколько карт OpenStreetMap в один файл с помощью Osmosis и развернули локальный tile-сервер для отображения карты в браузере. Данный стек позволяет эффективно работать с большими геоданными прямо в среде Windows.
